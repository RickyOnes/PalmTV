# PalmTV · 掌上电视 —— 三端网络电视直播播放器

> **Windows**（C# / WPF + LibVLC） · **Android**（Kotlin / Compose + Media3） · **HarmonyOS**（ArkTS + 原生 AVPlayer）
>
> 三端共用一套频道清单、一套节目单语义、一套交互文案 —— 同一个播放器，三种内核。

本工程把「频道清单 → 取流 → 本地中转 / 解密 → 播放 → 节目单 / 回看」整条链路做完：
不内嵌网页、不依赖系统浏览器内核、不在仓库里携带任何媒体内容。

---

## 亮点

- **自定义 IPTV 源**：手机 / 电视 / 电脑都能自己加源（m3u 粘贴即用，三端同一种格式、同一份清单）
- **换台快、播放稳**：换台预取（提前连源站、预下首片）、分片缓存复用、播放器复用不重建；
  出错按类型自愈（重取流 / 重建播放器），无信号自动退回原台
- **装在哪都能用**：Windows 电脑解压即用；Android 手机 / 平板 / **智能电视 / 电视盒子** 同一个包
- **内置 80 个频道**：**央视 24 / 卫视 32 / 地方台 24**，可继续扩展
- **10 天节目单 + 回看 + 时移**：移动端还支持**左右滑动时移**（每 40vp ≈ 10 秒）

### 本版重点

- **换台更快、更流畅**：换台时并行预热源站连接与首片、分片缓存复用、播放器实例复用（不重建画面）；
  起播看门狗（8 秒无数据自动重取）、播放错误按类型自愈。
- **节目单重做**：一次拉取「前 6 天 + 今天 + 后 3 天」共 10 天，弹窗按天分组；
  每 30 秒与服务端对齐一次（只重拉当天，其余日期不重复请求），跨点本地自动推进。
- **回看 / 时移**：已播完且允许回看的节目可整档回看（播完自动接下一档）；
  正在直播的节目可“时移”（从 5 分钟前起播，滚动窗口持续延迟直播）；节目条一键「返回直播」。
- **移动端手势时移**：视频区**左右滑动**调整播放位置（每 40vp ≈ 10 秒，松手统一结算一次），
  左滑后退、右滑前进，追到直播沿即回到直播。
- **日期 TAB 语义统一**：正在看的那天始终**红粗**（切到别的日期也不变色）；
  另外选中的日期为**紫色**；“今天”在非观看态为**绿色**；其余灰色。
- **节目条**：直播中红粗、回看中红粗；回看期间的“正在直播”整行**绿粗**并标注「直播」；
  没有节目单的频道统一显示「暂无节目单」。
- **稳定性**：外部源起播前预检（6 秒）、直连源 15 秒未出画判无信号 ⇒ 自动回退原台并点名提示。

## 三次重大迭代

| | 第一代 v1.0.x | 第二代 v1.1.0 → v1.1.8 | 第三代 v1.2.0 → v3.11.10（当前） |
|---|---|---|---|
| 端数 | Windows 单端 | Windows + HarmonyOS | **Windows + Android + HarmonyOS** |
| 播放方式 | 内嵌浏览器内核 + 网页播放器 | 原生内核（LibVLC / AVPlayer） | 原生内核（LibVLC / Media3 / AVPlayer） |
| 媒体处理 | 网页内脚本解密，与界面抢同一线程 | 原生模块，独立于界面线程 | 原生解密 + SM4-CBC 软解，异步串行 |
| 本地中转 | 独立反向代理进程（127.0.0.1:18888） | 进程内本地 HTTP 服务 | 三端各自的本地服务 / 数据源层 |
| 外部依赖 | 需系统 WebView2 运行时 | 无（播放器随包） | 无 |
| 节目单 | 当天，只在状态栏滚动 | 当天 + 弹层 | **10 天 + 回看 + 时移 + 自动接档** |
| 包体积 | ≈61 MB | ≈95 MB | 桌面 91.6 MB / 安卓 14.8 MB |

**第一代（v1.0.x）—— 能用，但基础不稳。**
播放页塞进系统 WebView2，靠独立代理进程托管页面、改写分片路径、转发请求，解密与签名都在页面脚本里。
整条链路依赖“页面已就绪”：注入失败、页面没起来，表现就是黑屏且难以排查；用户机还得装 WebView2 运行时。

**第二代（v1.1.0 → v1.1.8）—— 换成原生内核，砍掉网页与脚本引擎。**
桌面改用自带 LibVLC、鸿蒙改用原生 AVPlayer，解密与签名搬进原生模块；删除播放页、注入与 wasm 资产，
改成“进程内本地 HTTP 中转 + 原生解密”。这一代同时把台标打包成单一容器文件、加入自定义 IPTV 源、
首启免责声明、取流预检与无信号回退。代价是包体变大（自带播放器），换来“零外部依赖 + 故障面收敛”。

**第三代（v1.2.0 → v3.11.10）—— 三端统一，补齐回看与时移。**
新增 Android 端（手机与电视同一个包，自动切换触摸 / 遥控双界面），三端的文案、配色、节目条、
节目单交互统一成一套规则；取流签名改为各端本地计算，加密频道改软解（SM4-CBC）；
鸿蒙侧 native 精简为单个模块；节目单从“当天”扩到 10 天，并加入回看、时移、自动接档。
当前 **v3.11.10** 就是这一代的稳定版。

## 功能一览（v3.11.10）

**播放与取流**
- 内置 80 个频道（央视 24 / 卫视 32 / 地方台 24），三端同一份清单
- **自定义 IPTV 源**：m3u 文本粘贴即导入，三端同格式、同一份清单；可增删改、重名自动去重
- 换台优化：源站连接与首片并行预热、分片缓存复用、播放器复用不重建（换台不黑屏）
- 起播看门狗：8 秒内无分片 ⇒ 自动重取一次；播放错误按类型自愈（重取流 / 重建播放器）
- 无信号回退：外部源起播预检（6 秒），直连源 15 秒未出画判无信号 ⇒ 自动退回原台并点名提示

**节目单 / 回看**
- 10 天节目单（前 6 / 今天 / 后 3），按天分组，打开时自动定位到“正在看的那档”并居中
- 每 30 秒与服务端对齐（只重拉当天）；节目跨点本地自动推进（10 秒粒度）
- 回看：整档 VOD（带结束时刻），播完自动接下一档；来源标记不可回看的只提示、不发请求
- 时移：直播中从 5 分钟前起播，滚动窗口持续延迟；节目条一键「返回直播」
- 手势时移（移动端）：视频区左右滑动，每 40vp ≈ 10 秒，松手统一结算一次

**界面与交互**
- 竖屏 / 横屏两套布局共用同一棵组件树（旋转不重建画面，避免黑屏）
- 控制条：播放 / 暂停、静音、全屏、锁屏；全屏 3 秒自动隐藏，单击唤出
- 手势：左半屏上下调亮度、右半屏上下调音量、左右滑动时移
- 台标：打包成单一容器文件，运行期解到缓存；无台标的频道用完整频道名文字瓷砖
- 首启免责声明、关于页、自定义源编辑、举报联系入口

**系统集成**
- 媒体播控卡片（标题 + 封面），锁屏 / 通知栏 / 耳机键可控
- 音频会话恒为“混音”模式：不抢占、不打断其它应用
- 后台策略：退后台即暂停并交还焦点，回前台按停留时长选择“轻量恢复 / 重新取流”

## 架构（第三代）

```
          频道清单（内置 80 + 自定义 m3u）
                    │
                    ▼
        取流编排：签名 / 票据 / 播放地址
                    │
        ┌───────────┴────────────┐
        │ 本地中转（127.0.0.1）  │  ← 桌面 / 鸿蒙
        │ 改写清单 + 取分片      │    （安卓在数据源层完成）
        │  ↓ 解密                │
        └───────────┬────────────┘
                    ▼
        播放器（LibVLC / Media3 / AVPlayer）
                    │
                    ▼
        节目单（10 天）→ 回看 / 时移 / 返回直播
```

- **桌面**：LibVLC 播放；进程内本地服务负责清单改写与解密；节目单直连节目单接口。
- **安卓**：Media3 + 自实现数据源，边取边解，播放器只看到可直接播放的数据（不占端口）。
- **鸿蒙**：AVPlayer + XComponent(SURFACE)；单体 N-API 模块（签名 + 解密）；
  ArkTS 侧两级优先级队列，播放器请求永远插在预热任务之前。

## 本仓库包含 / 不包含

本仓库是**应用层源码**：可直接阅读、修改界面与业务逻辑，但**不等于“clone 即可编译出可运行包”**。

**包含**：三端界面与业务逻辑、节目单 / 回看 / 时移、自定义源、手势与播控、构建脚本。

**不包含（有意不随仓库分发）**：
- 平台身份与签名材料（应用凭据、证书、密钥库、Profile）——相关位置以 `YOUR_*` 占位；
- 取流签名与媒体解密的具体实现——只保留接口声明与构建配置（见 `NOTICE.md`）；
- 台标 / 图标等打包资产与运行期数据文件。

## 诊断

| 端 | 日志 |
|---|---|
| Windows | 启动参数 `--log`；运行目录日志；状态栏给出取流耗时 |
| Android | `adb logcat`（按包名过滤）；电视版按遥控「菜单」开诊断浮层 |
| HarmonyOS | `hdc shell hilog`（按应用 / 模块 tag 过滤） |

排错顺序：先确认“取流是否成功”，再看“本地服务有没有拿到分片”，最后看“播放器是否出画”。
