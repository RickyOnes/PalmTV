# 原生实现（未公开）

本目录**不放实现**，只按模块列出职责，便于理解整体结构。
补齐这些文件（并提供 `common/thirdparty/` 下的依赖）后，`CMakeLists.txt` 即可按原样编译。

| 模块 | 职责 |
|---|---|
| 请求签名 | 参数排序 + 摘要，生成请求所需的签名串 |
| 签名参数生成 | 按频道 / 时间戳 / 设备标识生成签名参数 |
| 辅助算法 | 摘要链路上用到的对称加密与序列化 |
| 流解密 | 加密流软解（SM4-CBC），按分片解出可播数据 |
| 解码编排 | 加密流的运行期环境、密钥与解码顺序 |
| TS 解复用 | MPEG-TS 解包（供解密链路使用） |
| 各端桥接 | N-API / JNI / P-Invoke 的导出层 |
| 直链签名 | 特定频道直链所需的签名 |
| 自测入口 | 本机单测入口与调试桩 |

> 上述实现均**不在本仓库**（见仓库根 `NOTICE.md`）。`include/` 下的头文件保留了接口声明，
> 实现需要自备；`CMakeLists.txt` 中对应条目已注释，放开即可编译。
